# coach-me

**Skills for Gen AI** · [English](README.md) · [繁體中文](README.zh-TW.md) · 简体中文 · [日本語](README.ja.md)

*A skill makes you own the real skill.*

一个 AI skill：**把你缺的知识和能力补齐，直到你能独立完成目标**，并经过验证。

## 为什么需要它

很多人用 grill-me 检验计划时，其实还不懂背后的知识，只是把 AI 给的推荐答案复制粘贴。结果项目停滞，或往错误的方向走。

coach-me 和 grill-me 分工，不重叠：

| | 检验什么 | 碰你的真实计划吗 |
|---|---|---|
| grill-me | 你的**决定**站不站得住 | 会 |
| coach-me | 你有没有**能力**自己做这个决定 | 不会，只用假设的旁支情境验证 |

## 安装

Claude Code（或任何支持 `SKILL.md` Agent Skills 格式的工具）：

```bash
git clone https://github.com/sagittarius1205/Coach-me ~/.claude/skills/coach-me
```

其他聊天型 AI：把 `SKILL.md` 的内容粘贴到系统提示词或自定义指令中。

## 两种用法

**1. 独立使用**：说"coach me""教会我…""我需要学什么才能…"。

- 单一技能：直接进入"诊断 → 教 → 你自己做 → 用新题目验证"的循环。
- 项目或大目标：先探测你的起点，把目标缩小成第一版，再给你一张最多 5 项的能力地图。

**2. 搭配 grill-me**：grill 的过程中，如果你出现以下任一种"盲从信号"，coach-me 会用一句话提议先补课，并说明原因：

- 直接采用推荐答案，或只回"好""照你说的"；
- 说不出自己选择的理由，只能重复 AI 说过的话；
- 说自己不懂某个术语或选项。

你可以拒绝。拒绝的话，那个决定会被标为 `⚠ 未验证理解`。接受的话，coach-me 只教判断这一题需要的知识，用假设情境验证，然后让你回到原题**先自己作答**，再看推荐答案。

## 示例：目标是日语 N1

coach-me 先用 1–2 题探测你的水平。假设你已经过了 N2：

```
日语 N1（第一版：N2 → N1 阅读与语法）  0/5

▶ 1. 能区分 N1 近义语法（〜ものを／〜ものの）   ← 当前
□ 2. 能读懂 N1 长文并指出作者主张
□ 3. 能在限时内完成一套阅读
□ 4. 能认出 N1 常考词汇（累积型）
□ 5. 能听懂自然语速的新闻（累积型）
⏸ 报考场次、教材选择 → grill-me
```

- 第 1–3 项在对话中教，用新题目验证，再针对你的答案追问一个细节。
- 第 4–5 项是累积型能力：coach-me 教你练习方法，设一个检查点（例如"随机 20 个词答对 16 个"）。你在对话外练习，回来后用新抽的题目验证。
- 听力在文字对话中无法验证，报告会如实写出"未测试"。

对话结束时会给你一张**进度卡**，下次粘贴回来就能接着继续。

## 它不会做的事

- 不替你做项目上的决定，那是 grill-me 的工作。
- 不给"熟练度 87 分"这种分数，只看你能不能独立完成具体任务。
- 不把对话中的通过当成正式资格或证书。
