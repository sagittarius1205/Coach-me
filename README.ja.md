# coach-me

**Skills for Gen AI** · [English](README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · 日本語

**足りない知識と能力を補い、目標を自力で達成できるようになるまで**教える AI スキルです。習得は検証で確かめます。

## なぜ必要か

grill-me で計画を検証するとき、背景知識を理解しないまま AI の推奨回答をコピペしてしまう人が少なくありません。その結果、プロジェクトが止まったり、間違った方向に進んだりします。

coach-me と grill-me は役割を分け、重なりません：

| | 何を検証するか | 実際の計画に触れるか |
|---|---|---|
| grill-me | あなたの**判断**が妥当か | 触れる |
| coach-me | その判断を自分で下す**能力**があるか | 触れない（仮想の別シナリオでのみ検証） |

## インストール

Claude Code（または `SKILL.md` Agent Skills 形式に対応したツール）：

```bash
git clone https://github.com/sagittarius1205/Coach-me ~/.claude/skills/coach-me
```

その他のチャット AI では、`SKILL.md` の内容をシステムプロンプトやカスタム指示に貼り付けてください。

## 2 つの使い方

**1. 単独で使う**：「coach me」「できるまで教えて」「〜するには何を学べばいい？」と伝えます。

- 単一のスキル：「診断 → 教える → 自分でやる → 新しい課題で検証」のループにすぐ入ります。
- プロジェクトや大きな目標：まず現在のレベルを確認し、目標を第一版に絞り込んでから、最大 5 項目の能力マップを提示します。

**2. grill-me と併用する**：grill の途中で次の「盲従シグナル」が出たら、coach-me が理由を添えて、一言で寄り道を提案します：

- 推奨回答をそのまま採用する、または「はい」「おまかせで」とだけ答える；
- AI の説明を繰り返す以外に、選んだ理由を説明できない；
- 用語や選択肢がわからないと言う。

断ることもできます。その場合、その判断には `⚠ 理解未検証` の印が付きます。受け入れた場合、coach-me はその一問の判断に必要な知識だけを教え、仮想シナリオで検証します。そのあと元の質問に戻り、推奨回答を見る**前に自分で答えて**もらいます。

## 例：日本語能力試験 N1 を目指す

coach-me はまず 1〜2 問でレベルを確認します。すでに N2 に合格しているとします：

```
JLPT N1（第一版：N2 → N1 読解と文法）  0/5

▶ 1. N1 の類似文法を区別できる（〜ものを／〜ものの）   ← 現在
□ 2. N1 の長文を読み、筆者の主張を言える
□ 3. 制限時間内に読解を 1 回分解ける
□ 4. N1 頻出語彙がわかる（積み上げ型）
□ 5. 自然な速さのニュースを聞き取れる（積み上げ型）
⏸ 受験時期・教材選び → grill-me
```

- 1〜3 は対話の中で教え、新しい課題で検証し、さらに回答の細部を一つ追加で質問します。
- 4〜5 は積み上げ型の能力です。coach-me は練習方法を教え、チェックポイント（例：「ランダムな 20 語中 16 語正解」）を設定します。練習は対話の外で行い、戻ってきたら新しく抽出した問題で検証します。
- 聴解はテキスト対話では検証できないため、レポートに「未テスト」と正直に書きます。

対話の最後に**進捗カード**が出ます。次回それを貼り付ければ続きから再開できます。

## しないこと

- プロジェクトの判断を代わりに下すこと（それは grill-me の役割です）。
- 「習熟度 87 点」のような点数を付けること（具体的な課題を自力でこなせるかだけを見ます）。
- 対話内での合格を正式な資格や認定として扱うこと。
